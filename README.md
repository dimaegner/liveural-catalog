# LiveUral — каталог мероприятий

Статический веб-каталог компании LiveUral. Сайт: https://dimaegner.github.io/liveural-catalog/ . Содержимое публикуется на GitHub Pages через GitHub Actions при каждом push в `main`.

## Локальный просмотр

Откройте `index.html` в браузере или запустите любой локальный HTTP-сервер в этой папке.

## Публикация

В настройках репозитория GitHub Pages в качестве источника публикации выберите **GitHub Actions**. После успешного запуска workflow адрес сайта появится во вкладке **Actions** и в настройках Pages.
